================================================================================
STEP 2: CREATING A VERSION
================================================================================

Each version = Master template + changes to these areas:

[A] HEADER COMMENT (lines 20-40)
    - Update name to edition name
    - Keep قدر يحيى & Dr. Mohamed Elgendy credits

[B] META TAGS (lines 220-250)
    - Update template-developer meta
    - Keep قدر يحيى & Dr. Mohamed Elgendy

[C] JSON-LD @GRAPH (lines ~515-1440)
    - Update SoftwareApplication.name to edition name
    - Set version to "1.0"
    - Schema types already adaptive — no changes needed

[D] CSS VARIABLES (Skin section, lines ~5500-6200)
    - Update --primary, --primary-dark, --accent colors
    - Each edition has its own color palette

[E] BRANDING STRINGS
    - Update default slogans, titles where applicable

================================================================================
STEP 4: AUTOMATED GENERATION (PowerShell)
================================================================================

Save this as generate-versions.ps1 and run from the repo root:

----[BEGIN SCRIPT]----
param(
  [string]$MasterPath = "اصل/RankTurboSeo.Apex.v16.original.1.xml",
  [string]$OutputDir = "اصل/Versions"
)

$editions = @(
  @{Name="English-Master"; Dir="001-English-Master"; Primary="#1E3A5F"; Dark="#0F2440"; Accent="#4A90D9"},
  @{Name="News-Portal"; Dir="002-News-Portal"; Primary="#1A237E"; Dark="#0D1444"; Accent="#E53935"},
  @{Name="Kitchen-Food"; Dir="003-Kitchen-Food"; Primary="#D4732F"; Dark="#B85C1D"; Accent="#E8B86D"},
  @{Name="Blog-Tech"; Dir="004-Blog-Tech"; Primary="#0D47A1"; Dark="#002171"; Accent="#00BCD4"},
  @{Name="Medical"; Dir="005-Medical"; Primary="#00695C"; Dark="#004D40"; Accent="#4DB6AC"},
  @{Name="AltMed"; Dir="006-Alternative-Med"; Primary="#2E7D32"; Dark="#1B5E20"; Accent="#81C784"},
  @{Name="Beauty"; Dir="007-Beauty-Mirror"; Primary="#AD1457"; Dark="#78002E"; Accent="#F48FB1"},
  @{Name="MedEng"; Dir="008-Medical-English"; Primary="#1565C0"; Dark="#003C8F"; Accent="#64B5F6"}
)

$master = Get-Content $MasterPath -Raw

foreach ($ed in $editions) {
  $xml = $master
  $xml = $xml -replace "RankTurboSeo Apex v16\.0", "RankTurboSeo $($ed.Name) v1.0"
  $xml = $xml -replace "--primary:.*#", "--primary: $($ed.Primary) /* "
  $xml = $xml -replace "--primary-dark:.*#", "--primary-dark: $($ed.Dark) /* "
  $xml = $xml -replace "--accent:.*#", "--accent: $($ed.Accent) /* "
  
  $outPath = "$OutputDir/$($ed.Dir)/RankTurboSeo-$($ed.Name).v1.0.xml"
  $xml | Set-Content $outPath
  Write-Host "Created: $outPath"
}
----[END SCRIPT]----
